📋 合作夥伴提交規範

歡迎成為海風的合作夥伴！請依照以下格式提供資訊，我們會幫你放到網站上。

📝 需要提供的資訊

1. 社群名稱
你的社群全名
2. 文宣 長度不拘
你的完整宣傳內容，會原封不動放在詳情頁上。可以自由發揮，想寫什麼就寫什麼。
3. 簡介 選填，20 字內
一句話介紹，會顯示在合作夥伴卡片上。可以自訂，例如「溫馨小社群，你的第二個遊樂天地」。沒寫的話我們會幫你從文宣裡抓重點。
4. Discord 邀請連結
https://discord.gg/xxxxx
5. 社群圖示 選填
請提供正方形圖片（建議 256×256 以上），格式 PNG 或 WebP。沒有的話，我們會用 Discord 伺服器圖示。
6. 社群類型
💬 群組
🌐 網站
🎮 Minecraft 伺服器
📦 其他

⚠️ 注意事項

✅文宣會原封不動放上去，不會修改你的內容，請放心書寫。
✅簡介可以自訂，如果沒寫，我們會幫你從文宣裡抓重點。
🔤可以使用一般符號（+×÷=!@#$% 等），但不支援 Markdown 排版（如 ~~、***、###、縮排等）。
📄如果文宣比較長，我們會幫你做一個專屬詳情頁。
⏱️提交後請等待確認，通常 1–3 天內會上線。

📮 提交方式

將填好的資訊直接私訊海風管理員，或在 Discord 開啟工單提交。
